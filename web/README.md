# Frontend Veterinaria - Aplicación Angular

Este directorio contiene la interfaz de usuario del **Sistema de Gestión Veterinaria**, desarrollada con **Angular 20** y **Angular Material**.

## Documentación completa

La documentación detallada del proyecto (instalación, stack, estructura, rutas, integración con backend, etc.) se encuentra en el archivo `README.md` de la carpeta padre.

## Tecnologías utilizadas

- Angular 20
- Angular Material 20 (UI componentes)
- TypeScript
- RxJS
- HttpClient para comunicación con API REST

## Entidades del sistema

- **Usuarios**: Autenticación y auditoría
- **Propietarios**: Dueños de mascotas
- **Mascotas**: Pacientes registrados
- **Citas**: Agendamiento de consultas
- **Facturas**: Gestión de pagos
- **Vacunas**: Control sanitario

## Comandos rápidos (ejecutar desde esta carpeta)

```bash
npm install          # Instalar dependencias
npm start            # Levantar servidor en http://localhost:4200
npm run build        # Compilar para producción (salida en dist/)
